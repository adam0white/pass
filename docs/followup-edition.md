# Follow-up edition

The title's **Try the follow-up edition** starts an explicit `pass@15` local run.
New game remains `pass@13`. Try the kitchen edition remains `pass@14`.
Existing saves never acquire the new behavior.

This edition retains the kitchen edition's stock, supplier failure, guest requests,
room work and ordinary conversations. It adds three finite host behaviors:

- **About what you said** selects a retained authored statement from this cook.
  **About the missed sunset prayer** appears only after Selim's actual evening
  report says he missed it. This topic keeps priority after an ordinary check-in.
  The newest actual prayer report supplies the source; other supported topics use
  the newest actual speech minute. The chef quotes the original words. HF decides whether
  the cook takes three minutes to discuss them instead of working. The source,
  decision and actual completion remain in the notebook. The conversation changes
  no prayer duty or faith score. It does not promise a later prayer outcome.
- A cook who accepts fifteen minutes in the dining room can carry an ordinary
  table's ready food. The carry reserves a clean plate and takes two service minutes.
  Payment and the used plate's return wait for service. An interrupted carry goes
  back to the existing pass handling; a departed table gets no completed delivery.
  This is physical waiter work by an existing cook, not a new person or qualification.
- After a refused request, the cook's actual chosen work owns attention until its
  next HF review or completion. Job requests cannot interrupt that same interval
  repeatedly. The cook explains the boundary and the kitchen keeps running.
  This is a work interval, not a refusal count, permanent silence or guaranteed
  departure. The earlier optional withdrawal/resignation choices remain voluntary.

These changes address bounded parts of GDI422, GDI003 and GDI008. They do not
establish all possible conversation topics, a dining-room staff simulation or
owner readiness. Evening reports count as prior speech only after that report
exists in the played run. No unseen biography supplies a conversation topic.

HF3.0.0 still owns cognition, choices, suggestion history and duties. The host owns
restaurant tasks, physical attention availability and conserved service events.
The existing last-cook coverage convention and request-answer trust workaround
remain; there is no new generic group-duty or trust engine here.
Published prompting/chronicle/review-cause adoption (GDI568/569/642) remains separate.
The package pins, cast, faith rules and default difficulty controls are unchanged.
